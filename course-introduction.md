# Course Introduction

CPELX230-330, CPE Elective 2 and 3 (Agentic Software Engineering)
Computer Engineering, National University, Term 2 2026-2027

CPELX230-330 introduces the principles, methods, and tools of Agentic Software Engineering, an emerging approach where AI agents take part in the software development lifecycle. The course covers how AI-powered systems can assist with requirements analysis, design, coding, testing, documentation, deployment, and maintenance. It puts a lot of weight on human-AI collaboration, prompt engineering, autonomous workflows, responsible AI practices, and checking the quality of agent-generated output.

Students learn by doing: Python, GitHub, AI, testing, and deployment activities, plus a team project that must include an AI agent, authorized tools or APIs, human oversight, security controls, automated testing, CI/CD, deployment, monitoring, and a responsible AI evaluation.

Weeks 2-4 cover the foundations:

- Agentic Software Engineering principles
- The Software Development Life Cycle (SDLC), Agile, and Scrum
- Git and GitHub workflow
- Responsible AI principles
- Team formation and the initial project proposal

Course policies I follow in this portfolio: no passwords, API keys, or personal data in the repository, honest reporting of limitations, and an AI Disclosure Statement for any AI-assisted work.

Required readings for this activity: Software Engineering by Ian Sommerville (Chapters 1 and 2), The Scrum Guide (2020), Pro Git (Chapters 1 and 2), Artificial Intelligence: A Modern Approach (Chapter 2), and the NIST AI Risk Management Framework.
