# Personal Learning Goals

My career path is leaning toward Cloud Networking or Cloud AI. These are my goals for this course:

1. Get comfortable with Git and GitHub, so my work is tracked, organized, and easy to share.
2. Learn how Agile and Scrum work in practice, and use them in group projects.
3. Understand how AI agents work, since Cloud AI is one of the paths I'm considering, and learn to use them as tools without trusting them blindly.
4. Practice deploying and monitoring software, which is also a skill I need for cloud work, including the CI/CD and deployment part of the course project.
5. Build responsible AI habits: checking AI output, protecting private data, and keeping a human in charge of important decisions.
6. Build soft skills like communication, teamwork, and documentation, so I'm ready to work in the industry.
